# TakNova AS

Statisk nettsted for GitHub Pages.

## Publisering
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Kontaktskjemaet bruker FormSubmit. Eieren må aktivere mottakeradressen ved første testinnsending og gjennomgå databehandler-/personvernforhold før produksjonsbruk. Takvelgeren er regelbasert, ikke AI. Løsningsbildene er inspirasjonsbilder; hero er en CSS-illustrasjon av et strekktak.
